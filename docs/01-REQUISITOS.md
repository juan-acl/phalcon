# 01 — Requisitos (resumen del enunciado)

**Objetivo:** aplicación web en PHP con framework (asignado: **Phalcon**) para registrar alumnos de una escuela de bachillerato y los cursos que aprobó cada uno.

## Funcional
1. **Alumnos:** nombres, apellidos (campos separados), fecha de nacimiento, fotografía, carrera (catálogo).
2. **Cursos aprobados por alumno:** semestre (catálogo), sección (catálogo), curso (catálogo), nota.
3. **Catálogos con interfaz de ingreso:** carreras, cursos, secciones, semestres.
4. **Ingreso de notas:** buscar al alumno primero y luego ingresar las notas de sus cursos.
5. **Reportes:**
   - General de alumnos por carrera
   - Notas por carrera, curso y sección
   - Consulta en pantalla de un alumno: toda su información + historial de notas

## Entregables
1. Demo funcionando con datos precargados, publicada en internet o equipo local (compartir URL).
2. PDF: manual técnico de publicación, pasos usados del framework, recomendaciones, comentarios del grupo sobre facilidad/dificultad.
3. Código fuente completo + instrucciones de publicación.
4. Un ZIP (PDF + código) a la plataforma.
